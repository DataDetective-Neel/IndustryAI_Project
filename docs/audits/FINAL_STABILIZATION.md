## Evidence and provenance

The supplied ELEGOO golden reference is a real photograph. The sibling defect
images are generated by the supplied dataset generator; they are controlled
fixtures, not independent photographs of physically damaged boards. Existing
pilot PCB photographs also exercise detection and board compatibility. No
real-world accuracy percentage is inferred from these tests.

The API acceptance runner exercised identical images, synthetic translation and
rotation, generated missing/displaced components, low-quality rejection, a
different pilot PCB, and reuse of saved manual landmarks. Identical and translated
images had 34 present components and no defects. The generated `missing_001`
fixture produced one missing decision (`U1` in the supplied map). Generated
`misaligned_002` produced one rotation decision (`U2`, -18 degrees). Names follow
the supplied map, not conflicting prose descriptions in the dataset README.
The rotated camera view aligned but left connector `J2` uncertain. Unrelated PCB
designs were rejected before component scoring. Raw evidence stays in ignored
`runs/final-stabilization/` and `runs/final-offline-api/`.

The fresh-process socket-blocked model verifier loaded both local models and
detected 61 reference components with zero network attempts. The nine-case API
acceptance runner also completed with external socket connections and external
DNS blocked, while allowing loopback: zero external network attempts. This
verifies local model loading and inspection processing, not detector coverage.

## Limitations

- ParsaVictor's configured `any_best.pt` is a generic locator. Fine component types
  are not fabricated. Some visible components remain undetected; manual inventory
  correction is supported. Detection confidence is not calibrated defect confidence.
- Shift/absence thresholds and correspondence gates are explicit but provisional.
  Independent physical missing/shifted/rotated PCB photographs remain necessary
  before accuracy claims or production calibration.
- Rotation hypotheses cover -30 to +30 degrees in 3-degree steps and require a
  structural score improvement. Large rotations, symmetry, reflection, blur, and
  insufficient texture may require review. No orientation is inferred from an
  axis-aligned bounding box.
- Browser camera transport uses synthetic video in automated checks. No physical
  camera device, lens distortion calibration, or sustained camera load was tested.
- Live-upload selection lasts for the running backend session. Saved Lab
  configurations persist. Existing local authentication does not require internet.
- Model socket blocking and local-asset checks are separate from physically
  disabling the computer's network adapter. No such adapter change was performed.
- Dense exported labels retain the existing placement heuristic; crowded boards
  may still have overlapping labels. Local inspection files have no retention policy.
