# AI collaboration history

## Scope and provenance

This index preserves the available project-related visible conversation records from local Codex sessions. It is a transcript export, not a replacement summary. Messages retain their wording and source order; timestamps use recorded UTC values. Each file identifies its session. Original pasted-text attachments are linked separately. Image attachment references are retained, but unavailable image bytes are not reconstructed.

System and developer instructions, tool calls/results, hidden reasoning, subagent conversations, authentication-related lines and local account names are excluded or explicitly redacted. Project source paths and ordinary project discussion remain. Session file names identify the provenance without publishing private account paths.

Redaction scope: credential assignments and login values are replaced line by line with explicit markers; local Windows account names are replaced in path prefixes. Injected skill/environment instructions and non-conversation records are omitted. Original user-authored project requirements remain as historical user messages/attachments, even when written as instructions; they are evidence, not active instructions. A final privacy review found no private company-representative conversations, unofficial-reviewer identities or internal company feedback to publish. Generic references to an evaluator/reviewer and the application’s proposed Supervisor role do not identify private people. Historical assistant status reports remain attributed messages, not newly verified results.

Original message links may name historical absolute paths, files subsequently moved, or ignored local run artifacts. They are retained verbatim as conversation evidence and are not guaranteed to work in a fresh checkout. Use the current [documentation index](../README.md) for supported document paths. Unavailable run outputs and image bytes are not silently reconstructed.
